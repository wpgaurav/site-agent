# Site Agent product page

Audience: WordPress developers using an MCP-compatible coding client on backed-up development and staging sites.

Primary query: Site Agent WordPress MCP plugin. Supporting language: WordPress MCP server, PHP execution, WP-CLI tools, WordPress Application Passwords, agent access controls.

Offer: Independently written, open-source plugin with ten named tools. FluentCart distribution and automatic updates are being added in the authorized launch workflow; do not claim the updater is verified until the delivery test passes. Pricing is free, with a free checkout license for updates.

Page job: Explain what the client can do, show entry-point permissions and full-privilege boundaries, state requirements, then offer one consistent checkout action and source-code access.

Art direction: An editorial control console, with a split hero, a single original bracket/network glyph, a permission matrix, interactive tool examples, and a light/dark palette inherited in spirit from the GT site. No copied Core Bookings composition, no Novamira material, no fabricated user counts or production claims. The graphic is conceptual branding, while code examples map to real tool names.

Page sections: Hero; connection mechanism; tool workbench; access boundaries; setup; offer; FAQ and final action. Inline page-owned PBB sections, scoped CSS, no shared library mutations, no PHP execution in authored blocks. Preserve the normal site header/footer.

Proof: Source definitions, actual authentication/schema tests, WordPress requirements, private ability exposure, encrypted updater state once implemented. Keep QA counts and production process out of buyer-facing copy.

September 30 design steering: follow the violet gradient, frosted framing, floating interface panel, pastel feature blocks, rounded actions and spacious rhythm of https://aichatbott.framer.website/. The user has commercial rights. Use original Site Agent content and artwork; no review counts, customer evidence or unsupported chatbot features transfer. This explicit direction supersedes the prior page palette and shape defaults.

Final color steering: the primary accent is dark blue #1b2733, with navy/slate gradients and pale blue surfaces. Preserve the Framer-inspired framing, spacing and interaction. The hero brand mark is presented in monochrome.
