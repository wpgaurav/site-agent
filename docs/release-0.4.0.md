# Site Agent 0.4.0

Adds opt-in OAuth 2.1 connections for MCP clients and lets other plugins add skills to `list-skills` and `get-skill`. Access defaults are unchanged: OAuth connections start off, like every tool group.

OAuth follows the MCP authorization specification. An unauthenticated MCP request answers 401 with a `WWW-Authenticate` pointer to RFC 9728 protected resource metadata. Site Agent's issuer is `…/wp-json/site-agent/v1/oauth`; its RFC 8414 metadata is served at the path-inserted well-known URL, the OpenID Connect forms and REST. Public clients register through RFC 7591, an administrator approves each on a wp-admin consent screen and picks its tool groups, PKCE S256 is required, and responses carry `iss`. Access tokens last one hour; refresh tokens rotate, end after 30 days without use, and reuse of a rotated token ends the connection. Tokens are stored as HMAC hashes in the approving user's meta, authenticate only the MCP route, narrow groups like per-password limits, and appear in audit history as `via: oauth` with the client name. Each registered client is its own non-autoloaded option. Uninstall removes clients and grants.

Testing on gauravtiwari.org found and fixed:

- Rank Math SEO bundles wp-media's MCP OAuth server, which serves the site-root `/.well-known/oauth-authorization-server` and `oauth-protected-resource` documents with the home URL as issuer. Site Agent first used the home URL too; it now uses its own issuer path and never answers the root documents.
- WordPress's canonical redirect adds a trailing slash to well-known paths; both forms are answered.
- Registrations and code exchanges rewrote one shared clients option, so concurrent writes on the open registration endpoint could drop a client mid-authorization. Clients are now stored separately.
- The consent screen needed a hidden admin page, because wp-admin refuses unregistered pages before `admin_init`.

The `site_agent_skills` filter registers read-only skill directories with `SKILL.md`. Names cannot replace the bundled builder skills, at most 20 are listed, and only Markdown, JSON and HTML files up to 64 KiB are served. GT Extensions for FluentCart 2.8.3 registers `gtfc-invoice` and `gtfc-quote`.
